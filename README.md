# Personal Portfolio — Bibi Hazaratun Nesa

Single-page personal portfolio built for **Synent Technologies Web Development Internship — Task 1 (Basic Level)**.

## Sections
- **Header / Hero** — name, role, and an animated "emotion signal" card that cycles through Bangla/Banglish sample sentences with their detected emotion tag, tying into my NLP thesis work
- **About Me** — background as a CSE student and NLP researcher
- **Skills** — grouped into NLP & ML, Web Development, and Tools & Practice
- **Contact** — GitHub, email, and LinkedIn

## Tech
- Plain **HTML5** and **CSS3** — no framework
- A small vanilla JS snippet powers the hero's text-cycling animation
- Fonts: Space Grotesk (display), Source Serif 4 (body), IBM Plex Mono (labels)
- Fully responsive — tested down to mobile widths
- Respects `prefers-reduced-motion` and has visible keyboard focus states
